# Resource: tfe_audit_trail_token

Generates a new audit trail token in organization, replacing any existing token.

-> **Note:** Only organizations that have the [audit-logging entitlement](https://developer.hashicorp.com/terraform/cloud-docs/api-docs#audit-logging) may create audit trail tokens.

## Example Usage

```terraform
# Basic usage

resource "tfe_audit_trail_token" "test" {
  organization = "my-org-name"
}
```

```terraform
# When a token has an expiry

resource "time_rotating" "example" {
  rotation_days = 30
}

resource "tfe_audit_trail_token" "test" {
  organization = data.tfe_organization.org.name
  expired_at   = time_rotating.example.rotation_rfc3339
}
```

## Schema

### Optional

- `expired_at` (String) The token's expiration date. The expiration date must be a date/time string in RFC3339 format (e.g., "2024-12-31T23:59:59Z"). If no expiration date is supplied, the token will expire 24 months from creation and a warning during plan and apply phases will be displayed.
- `force_regenerate` (Boolean) If set to `true`, a new token will be generated even if a token already exists. This will invalidate the existing token!
- `organization` (String) Name of the organization. If omitted, organization must be defined in the provider config.

### Read-Only

- `id` (String) The ID for the audit trail token.
- `token` (String, Sensitive) The authentication token for accessing Audit Trails.
