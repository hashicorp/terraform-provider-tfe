# Resource: tfe_admin_organization_settings

(Only for Terraform Enterprise) Manages admin settings for an organization.

This resource requires the use of an admin token. See example usage for incorporating an admin token in your provider config.

## Example Usage

```terraform
# Basic usage

variable "token" {
  description = "An access token"
}

variable "admin_token" {
  description = "An admin access token"
}

variable "hostname" {
  description = "The HCP Terraform or Enterprise hostname."
  default     = "app.terraform.io"
}

provider "tfe" {
  hostname = var.hostname
  token    = var.token
}

provider "tfe" {
  alias    = "admin"
  hostname = var.hostname
  token    = var.admin_token
}

resource "tfe_organization" "a-module-producer" {
  name  = "my-org"
  email = "admin@example.com"
}

resource "tfe_organization" "a-module-consumer" {
  name  = "my-other-org"
  email = "admin@example.com"
}

resource "tfe_admin_organization_settings" "test-settings" {
  provider              = tfe.admin
  organization          = tfe_organization.a-module-producer.name
  workspace_limit       = 15
  access_beta_tools     = false
  global_module_sharing = false
  module_sharing_consumer_organizations = [
    tfe_organization.a-module-consumer.name
  ]
}
```

## Schema

### Optional

- `access_beta_tools` (Boolean) If true, the organization has access to beta tool versions.
- `global_module_sharing` (Boolean) If true, modules in the organization's private module repository will be available to all other organizations. Enabling this will disable any previously configured `module_sharing_consumer_organizations`. Cannot be true if `module_sharing_consumer_organizations` is set.
- `module_sharing_consumer_organizations` (Set of String) A list of organization names with which to share modules in the organization's private module repository. Cannot be set if `global_module_sharing` is true.
- `organization` (String) Name of the organization. If omitted, organization must be defined in the provider config.
- `workspace_limit` (Number) Maximum number of workspaces for this organization. If this number is set to a value lower than the number of workspaces the organization has, it will prevent additional workspaces from being created, but existing workspaces will not be affected. If set to 0, this limit will have no effect.

### Read-Only

- `id` (String) The ID of this resource. Do not rely on this value — use `organization` instead.
- `sso_enabled` (Boolean) If true, SSO is enabled in this organization.
