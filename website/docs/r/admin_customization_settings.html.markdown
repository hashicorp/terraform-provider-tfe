# Resource: tfe_admin_customization_settings

(Only for Terraform Enterprise) Manages the admin customization settings, including support and documentation link routing, avatar source configuration, and login/footer/error/new-user messaging.

Requires admin token configuration. See example usage for incorporating an admin token in your provider config.

Requires Terraform Enterprise v2.1.0 or later.

This is a singleton resource: there is only ever one set of customization settings for a TFE instance. Destroying this resource restores managed attributes to the values that were in effect before Terraform managed them. If an imported resource is destroyed without having modified any settings, Terraform Enterprise settings remain unchanged.

All attributes are optional; any attribute omitted from configuration keeps its current server-side value. Removing an attribute from configuration does not reset it — set it explicitly (for example, to an empty string) instead.

## Example Usage

```terraform
# Manage admin customization settings for a Terraform Enterprise instance.

variable "admin_token" {
  description = "An admin access token"
}

variable "hostname" {
  description = "The HCP Terraform or Enterprise hostname."
  default     = "app.terraform.io"
}

provider "tfe" {
  hostname = var.hostname
  token    = var.admin_token
}

resource "tfe_admin_customization_settings" "this" {
  support_email              = "support@example.com"
  internal_support_url       = "https://internal.example.com/support"
  internal_documentation_url = "https://internal.example.com/docs"
  internal_tutorials_url     = "https://internal.example.com/tutorials"
  login_help                 = "<p>Contact your administrator for help signing in.</p>"
  footer                     = "<p>© Example Corp</p>"
  error                      = "<p>Something went wrong. Please contact support.</p>"
  new_user                   = "<p>Welcome to Terraform Enterprise!</p>"

  avatar_sources = {
    gravatar = true
  }
}
```

## Schema

### Optional

- `avatar_sources` (Map of Boolean) A map of avatar source name to whether it is enabled (for example `{ gravatar = true }`). Source names are validated against the avatar sources known to the provider's API client (currently `gravatar`); new sources require a provider upgrade. Only the sources you specify are managed by Terraform; any others reported by Terraform Enterprise are left untouched. If omitted, the current configuration is preserved.
- `error` (String) Custom instructions shown to users when an error occurs. Set to an empty string to clear it.
- `footer` (String) Custom footer content shown throughout the application. Set to an empty string to clear it.
- `internal_documentation_url` (String) An internal documentation URL that overrides the default HashiCorp documentation link. Accepts an `https://` or `http://` value. Set to an empty string to clear the override and restore the default link.
- `internal_support_url` (String) An internal support URL that overrides the default HashiCorp support link. Accepts an `https://`, `http://`, or `mailto:` value. Set to an empty string to clear the override and restore the default link.
- `internal_tutorials_url` (String) An internal tutorials URL that overrides the default HashiCorp tutorials link. Accepts an `https://` or `http://` value. Set to an empty string to clear the override and restore the default link.
- `login_help` (String) Custom help text shown on the login page. Set to an empty string to clear it.
- `new_user` (String) Custom instructions shown to new users. Set to an empty string to clear it.
- `support_email` (String) The support email address presented to users. Set to an empty string to clear it, in which case `support_url_address` is used instead.
- `support_url_address` (String) The support hostname presented to users, without a scheme (for example, `support.example.com`). Terraform Enterprise adds the scheme when rendering the link. Used as the fallback when `support_email` is not set. Terraform Enterprise requires this value, so it cannot be empty.

### Read-Only

- `id` (String) The ID of the customization settings.
