# Resource: tfe_admin_general_settings

(Only for Terraform Enterprise) Manages the admin general settings.

Requires admin token configuration. See example usage for incorporating an admin token in your provider config.

Requires Terraform Enterprise v2.1.0 or later.

This is a singleton resource: there is only ever one set of general settings for a TFE instance. Destroying this resource restores managed attributes to the values that were in effect before Terraform managed them. If an imported resource is destroyed without having modified any settings, Terraform Enterprise settings remain unchanged.

## Example Usage

```terraform
# Manage admin general settings for a Terraform Enterprise instance.

variable "admin_token" {
  description = "An admin access token"
}

variable "hostname" {
  description = "The HCP Terraform or Enterprise hostname."
  default     = "app.terraform.io"
}

provider "tfe" {
  hostname = var.hostname
  token    = var.admin_token
}

resource "tfe_admin_general_settings" "this" {
  enable_public_registration = true
}
```
