# Resource: tfe_admin_banner

Manages a site-wide announcement banner on a Terraform Enterprise instance. This resource is not supported on HCP Terraform.

Declaring this resource publishes the banner; destroying it deactivates the banner.

~> **NOTE:** Only one non-deactivated banner can exist on a Terraform Enterprise instance at a time. Applying a second `tfe_admin_banner` resource fails with a `409 Conflict` error.

~> **NOTE:** Terraform Enterprise sanitizes `body` on save, stripping any HTML tag or attribute that is not allowlisted. If `body` contains disallowed markup, the stored value differs from the configuration and `terraform plan` reports a perpetual diff.

## Example Usage

```terraform
# Publish an immediate, site-wide announcement banner

variable "admin_token" {
  description = "An admin access token"
}

variable "hostname" {
  description = "The Terraform Enterprise hostname."
}

provider "tfe" {
  hostname = var.hostname
  token    = var.admin_token
}

resource "tfe_admin_banner" "maintenance" {
  title    = "Scheduled maintenance"
  body     = "Terraform Enterprise will be <strong>unavailable</strong> on Sunday. See the <a href=\"https://status.example.com\">status page</a>."
  style    = "warning"
  audience = "all_users"
}
```

```terraform
# Schedule a banner to appear and expire automatically.
# scheduled_publish_at, scheduled_expire_at and timezone must be set together.
# The banner remains in Terraform state after it expires; remove the resource
# from your configuration (or run `terraform destroy`) to deactivate it.

variable "admin_token" {
  description = "An admin access token"
}

variable "hostname" {
  description = "The Terraform Enterprise hostname."
}

provider "tfe" {
  hostname = var.hostname
  token    = var.admin_token
}

resource "tfe_admin_banner" "maintenance_window" {
  title                = "Maintenance window"
  body                 = "Planned maintenance from 02:00 to 04:00 UTC."
  style                = "warning"
  audience             = "authenticated_only"
  scheduled_publish_at = "2026-12-06T00:00:00Z"
  scheduled_expire_at  = "2026-12-06T04:00:00Z"
  timezone             = "UTC"
}
```

## Schema

### Required

- `body` (String) The body text of the banner. Limited HTML is allowed: `<strong>`, `<em>`, `<b>`, `<i>`, and `<a href>` with `http`, `https`, or `mailto` links. All other tags and attributes are stripped by the server. Maximum 500 characters after sanitization. If the configured value contains disallowed markup, the server strips it and the next `terraform plan` will show a diff. Update the configuration to match the stored value to resolve the diff.
- `title` (String) The short heading of the banner. Maximum 100 characters.

### Optional

- `audience` (String) Which users see the banner. Valid values are `all_users` and `authenticated_only`. Defaults to `authenticated_only`.
- `scheduled_expire_at` (String) The date and time, in RFC3339 format, when the banner stops being visible. Must be after `scheduled_publish_at`. If set, `scheduled_publish_at` and `timezone` must also be set. An expired banner is not destroyed automatically; remove the resource from the configuration to deactivate it.
- `scheduled_publish_at` (String) The date and time, in RFC3339 format (e.g., `2026-12-31T22:00:00Z`), when the banner becomes visible. If set, `scheduled_expire_at` and `timezone` must also be set. If omitted, the banner is published immediately.
- `style` (String) The visual style of the banner. Valid values are `info`, `warning`, and `critical`. Defaults to `info`.
- `timezone` (String) The IANA timezone identifier (e.g., `America/New_York`) used to display the schedule in the UI. If set, `scheduled_publish_at` and `scheduled_expire_at` must also be set.

### Read-Only

- `id` (String) The ID of the banner.
- `published_at` (String) The date and time, in RFC3339 format, when the banner was published.
