# Resource: tfe_hyok_configuration

Manages a HYOK configuration.

~> **Note:** This resource requires using the provider with HCP Terraform on the HCP Terraform Premium edition. Refer to [HCP Terraform pricing](https://www.hashicorp.com/en/pricing?product_intent=terraform&tab=terraform) for details.

## Example Usage

```terraform
# Basic usage

resource "tfe_gcp_oidc_configuration" "gcp" {
  service_account_email  = "myemail@gmail.com"
  project_number         = "11111111"
  workload_provider_name = "projects/1/locations/global/workloadIdentityPools/1/providers/1"
  organization           = "my-org-name"
}

resource "tfe_hyok_configuration" "example" {
  organization            = "my-hyok-org"
  name                    = "my-key-name"
  kek_id                  = "key1"
  agent_pool_id           = "apool-MFtsuFxHkC9pCRgB"
  oidc_configuration_id   = tfe_gcp_oidc_configuration.gcp.id
  oidc_configuration_type = "gcp"

  kms_options {
    key_location = "global"
    key_ring_id  = "example-key-ring"
  }
}
```

## Schema

### Required

- `agent_pool_id` (String) The ID of the agent-pool to associate with the HYOK configuration.
- `kek_id` (String) Refers to the name of your key encryption key stored in your key management service.
- `name` (String) Label for the HYOK configuration to be used within HCP Terraform.
- `oidc_configuration_id` (String) The ID of the TFE OIDC configuration. This is typically sourced from another OIDC configuration resource corresponding with the target cloud provider, such as `tfe_oidc_configuration_gcp`, `tfe_oidc_configuration_aws`, or `tfe_oidc_configuration_azure`.
- `oidc_configuration_type` (String) The type of the TFE OIDC configuration. Valid values are `vault`, `aws`, `gcp`, and `azure`.

### Optional

- `kms_options` (Block, Optional) Optional object used to specify additional fields for some key management services. (see [below for nested schema](#nestedblock--kms_options))
- `organization` (String) Name of the organization. If omitted, organization must be defined in the provider config.

### Read-Only

- `id` (String) The ID of the HYOK configuration.

### Nested Schema for `kms_options`

Optional:

- `key_location` (String) The location in which the GCP key ring exists.
- `key_region` (String) The AWS region where your key is located.
- `multi_region` (Boolean) Whether the AWS key is multi-region a key.
- `key_ring_id` (String) The root resource for Google Cloud KMS keys and key versions.
