# Resource: tfe_organization_token

Generates a new organization token, replacing any existing token, which can be used to act as the organization service account.

## Example Usage

```terraform
# Basic usage

resource "tfe_organization_token" "test" {
  organization = "my-org-name"
}
```

```terraform
# When a token has an expiry

resource "time_rotating" "example" {
  rotation_days = 30
}

resource "tfe_organization_token" "test" {
  organization = data.tfe_organization.org.name
  expired_at   = time_rotating.example.rotation_rfc3339
}
```

## Schema

### Optional

- `expired_at` (String) The token's expiration date. The expiration date must be a date/time string in RFC3339 format (e.g., "2024-12-31T23:59:59Z"). If no expiration date is supplied, the token will expire 24 months from creation.
- `force_regenerate` (Boolean) If set to `true`, a new token will be generated even if a token already exists. This will invalidate the existing token!
- `organization` (String) Name of the organization. If omitted, organization must be defined in the provider config.

### Read-Only

- `id` (String) The ID of the token.
- `token` (String, Sensitive) The generated token.
