# Resource: tfe_ssh_key

Manages an SSH key which includes a name and the SSH private key. An organization can have multiple SSH keys available.

## Example Usage

```terraform
# Basic usage

resource "tfe_ssh_key" "test" {
  name         = "my-ssh-key-name"
  organization = "my-org-name"
  key          = "private-ssh-key"
}
```

```terraform
# With write-only key

variable "ssh_key" {
  type      = string
  ephemeral = true
}

resource "tfe_ssh_key" "test" {
  name           = "my-ssh-key-name"
  organization   = "my-org-name"
  key_wo         = var.ssh_key
  key_wo_version = 1
}
```

## Schema

### Required

- `name` (String) The name of the SSH key.

### Optional

> **NOTE**: [Write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) are supported in Terraform 1.11 and later.

- `key` (String, Sensitive) The text of the SSH private key. One of `key` or `key_wo` must be provided.
- `key_wo` (String, Sensitive, [Write-only](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments)) The text of the SSH private key, guaranteed not to be written to plan or state artifacts. One of `key` or `key_wo` must be provided. Must be used with `key_wo_version`.
- `key_wo_version` (Number) Version of the write-only key. This field is used to trigger updates when the write-only key changes. Must be used with `key_wo`. When `key_wo_version` changes, the write-only key will be updated.
- `organization` (String) The name of the organization. If omitted, organization must be defined in the provider config.

### Read-Only

- `id` (String) ID of the SSH key.
