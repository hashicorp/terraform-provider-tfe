# Resource: tfe_registry_artifact_tag

Manages the tags assigned to a registry artifact, such as a private registry module, provider, or component.

~> **NOTE:** This resource manages the *complete* set of tags on an artifact. The tags declared in the configuration replace any tags that already exist on the artifact, including tags created outside of Terraform. Destroying this resource removes all tags from the artifact.

## Example Usage

Basic usage:

```terraform
data "tfe_registry_module" "example" {
  organization    = "my-org-name"
  name            = "my-module"
  module_provider = "aws"
}

resource "tfe_registry_artifact_tag" "example" {
  artifact = {
    type = "registry-module"
    id   = data.tfe_registry_module.example.id
  }

  tags = [
    {
      key   = "environment"
      value = "production"
    },
    {
      key   = "team"
      value = "platform"
    },
  ]
}
```

Tagging a private provider:

```terraform
data "tfe_registry_provider" "example" {
  organization = "my-org-name"
  name         = "my-provider"
}

resource "tfe_registry_artifact_tag" "provider_tags" {
  artifact = {
    type = "registry-provider"
    id   = data.tfe_registry_provider.example.id
  }

  tags = [
    {
      key   = "tier"
      value = "internal"
    },
  ]
}
```
