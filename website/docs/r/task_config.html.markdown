# Resource: tfe_task_config

Manages the global configuration for an organization run task. This resource manages the same task configuration as `tfe_organization_run_task_global_settings`; do not manage the same owner and task with both resources. Destroying this resource disables the configuration.

## Example Usage

```terraform
resource "tfe_organization_run_task" "example" {
  organization = "my-org-name"
  url          = "https://external.service.com"
  name         = "example-task"
  enabled      = true
  description  = "An example run task"
}

resource "tfe_task_config" "example" {
  owner             = "my-org-name"
  task_id           = tfe_organization_run_task.example.id
  enabled           = true
  enforcement_level = "advisory"
  stages            = ["pre_plan", "post_plan"]
}
```

## Schema

### Required

- `enforcement_level` (String) The enforcement level of the global task. Valid values are `advisory` and `mandatory`.
- `stages` (List of String) Which stages the task will run in. Valid values are one or more of `pre_plan`, `post_plan`, `pre_apply` and `post_apply`.
- `task_id` (String) The ID of the run task to configure.

### Optional

- `enabled` (Boolean) Whether the run task is applied globally.
- `owner` (String) The name of the organization that owns the task configuration. If omitted, the provider-level organization must be configured.

### Read-Only

- `id` (String) The ID of the task configuration.

Resource tfe_task_config can be imported in the following format:
