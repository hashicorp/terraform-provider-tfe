# Resource: tfe_task_config

Creates, updates and destroys the configuration of an [Organization Run task](https://developer.hashicorp.com/terraform/cloud-docs/workspaces/settings/run-tasks), controlling the stages it runs in, its enforcement level, and whether it applies globally or to specific projects.

## Example Usage

```terraform
resource "tfe_organization_run_task" "example" {
  organization = "my-org-name"
  url          = "https://external.service.com"
  name         = "task-name"
}

# Apply the task to every workspace in the organization
resource "tfe_task_config" "global" {
  task_id           = tfe_organization_run_task.example.id
  global            = true
  enforcement_level = "mandatory"
  stages            = ["post_plan"]
}

# Apply the task to the workspaces of specific projects
resource "tfe_project" "testproject" {
  organization = "my-org-name"
  name         = "test-project-name"
}

resource "tfe_task_config" "projects" {
  task_id           = tfe_organization_run_task.example.id
  enforcement_level = "advisory"
  stages            = ["pre_plan", "post_plan"]
  project_ids       = [tfe_project.testproject.id]
}
```

## Schema

### Required

- `enforcement_level` (String) The enforcement level of the task. Valid values are `advisory` and `mandatory`.
- `stages` (Set of String) The stages the task will run in. Valid values are one or more of `pre_plan`, `post_plan`, `pre_apply` and `post_apply`.
- `task_id` (String) The ID of the run task this configuration applies to.

### Optional

- `global` (Boolean) Whether the run task applies to all workspaces in the organization. Cannot be true when `project_ids` is set.
- `organization` (String) Name of the organization that owns the task. If omitted, organization must be defined in the provider config.
- `project_ids` (Set of String) The IDs of the projects the task applies to. Cannot be set when `global` is true.

### Read-Only

- `id` (String) The ID of the task config.
- `owner_id` (String) The ID of the resource that owns the task config. Currently always the organization.
