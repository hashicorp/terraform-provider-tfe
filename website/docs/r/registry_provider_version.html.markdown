# Resource: tfe_registry_provider_version

Manages provider versions in the private registry.

## Example Usage

```terraform
# Create a private provider version

resource "tfe_registry_provider" "example" {
  organization = tfe_organization.example.name
  name         = "my-provider"
}

resource "tfe_registry_gpg_key" "example" {
  organization = tfe_organization.example.name
  ascii_armor  = file("my-public-key.asc")
}

resource "tfe_registry_provider_version" "example" {
  organization = tfe_registry_provider.example.organization
  name         = tfe_registry_provider.example.name
  version      = "1.0.0"
  key_id       = tfe_registry_gpg_key.example.id
  protocols    = ["5.0"]
}
```

```terraform
# Create a public provider version

resource "tfe_registry_provider" "example" {
  organization = tfe_organization.example.name
  name         = "my-provider"
}

resource "tfe_registry_gpg_key" "example" {
  organization = tfe_organization.example.name
  ascii_armor  = file("my-public-key.asc")
}

resource "tfe_registry_provider_version" "example" {
  organization  = tfe_registry_provider.example.organization
  registry_name = "public"
  namespace     = "hashicorp"
  name          = tfe_registry_provider.example.name
  version       = "5.0.0"
  key_id        = tfe_registry_gpg_key.example.id
  protocols     = ["5.0", "6.0"]
}
```

```terraform
# Create a private provider version with SHASUMS files

resource "tfe_registry_provider" "example" {
  organization = tfe_organization.example.name
  name         = "my-provider"
}

resource "tfe_registry_gpg_key" "example" {
  organization = tfe_organization.example.name
  ascii_armor  = file("my-public-key.asc")
}

resource "tfe_registry_provider_version" "example" {
  organization     = tfe_registry_provider.example.organization
  name             = tfe_registry_provider.example.name
  version          = "1.0.0"
  key_id           = tfe_registry_gpg_key.example.id
  protocols        = ["5.0"]
  shasums_file     = "https://releases.example.com/my-provider/1.0.0/my-provider_1.0.0_SHA256SUMS"
  shasums_sig_file = "https://releases.example.com/my-provider/1.0.0/my-provider_1.0.0_SHA256SUMS.sig"
}
```

## Schema

### Required

- `key_id` (String) The GPG key ID used to sign the provider version.
- `name` (String) Name of the provider.
- `protocols` (List of String) An array of Terraform provider API versions that this version supports.
- `version` (String) A valid semver version string.

### Optional

- `namespace` (String) The namespace of the provider. For private providers this is the same as the organization.
- `organization` (String) Name of the organization. If omitted, organization must be defined in the provider config.
- `registry_name` (String) Whether this is a publicly maintained provider or private. Must be either `public` or `private`. Defaults to `private`.
- `shasums_file` (String) Path to the SHASUMS file (local file path or HTTP/HTTPS URL). Optional - if not provided, SHASUMS must be uploaded separately.
- `shasums_sig_file` (String) Path to the SHASUMS signature file (local file path or HTTP/HTTPS URL). Optional - if not provided, signature must be uploaded separately.

### Read-Only

- `created_at` (String) The time when the provider version was created.
- `id` (String) ID of the provider version.
- `shasums_sig_uploaded` (Boolean) Indicates whether the SHASUMS signature file has been uploaded.
- `shasums_uploaded` (Boolean) Indicates whether the SHASUMS file has been uploaded.
- `updated_at` (String) The time when the provider version was last updated.



## Import

tfe_registry_provider_version can be imported using an identity. For example:

```terraform
import {
  to = tfe_registry_provider_version.example
  identity = {
    id            = "provver-y5KZUsSBRLV9zCtL"
    organization  = "my-org-name"
    registry_name = "private"
    namespace     = "my-org-name"
    name          = "my-provider"
    version       = "1.0.0"
    hostname      = "app.terraform.io"
  }
}
```
