# Resource: tfe_vault_oidc_configuration

Manages a Vault OIDC configuration.

~> **Note:** This resource requires using the provider with HCP Terraform on the HCP Terraform Premium edition. Refer to [HCP Terraform pricing](https://www.hashicorp.com/en/pricing?product_intent=terraform&tab=terraform) for details.

## Example Usage

```terraform
# Basic usage

resource "tfe_vault_oidc_configuration" "example" {
  address        = "https://my-vault-cluster-public-vault-659decf3.b8298d98.z1.hashicorp.cloud:8200"
  role_name      = "vault-role-name"
  namespace      = "admin"
  auth_path      = "jwt-auth-path"
  encoded_cacert = ""
  organization   = "my-org-name"
}
```

## Schema

### Required

- `address` (String) The full address of your Vault instance.
- `namespace` (String) The namespace your JWT auth path is mounted in.
- `role_name` (String) The name of a role in your Vault JWT auth path, with permission to encrypt and decrypt with a Transit secrets engine key.

### Optional

- `auth_path` (String) The mount path of the JWT authentication method. Defaults to `"jwt"`.
- `encoded_cacert` (String) A base64 encoded certificate which can be used to authenticate your Vault certificate. Only needed for self-hosted Vault Enterprise instances with a self-signed certificate.
- `organization` (String) Name of the organization. If omitted, organization must be defined in the provider config.

### Read-Only

- `id` (String) The ID of the Vault OIDC configuration.
