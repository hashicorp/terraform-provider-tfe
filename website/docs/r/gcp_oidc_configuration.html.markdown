# Resource: tfe_gcp_oidc_configuration

Manages a GCP OIDC configuration.

~> **Note:** This resource requires using the provider with HCP Terraform on the HCP Terraform Premium edition. Refer to [HCP Terraform pricing](https://www.hashicorp.com/en/pricing?product_intent=terraform&tab=terraform) for details.

## Example Usage

```terraform
# Basic usage

resource "tfe_gcp_oidc_configuration" "example" {
  service_account_email  = "myemail@gmail.com"
  project_number         = "11111111"
  workload_provider_name = "projects/1/locations/global/workloadIdentityPools/1/providers/1"
  organization           = "my-org-name"
}
```

## Schema

### Required

- `project_number` (String) The GCP Project containing the workload provider and service account.
- `service_account_email` (String) The email of your GCP service account, with permissions to encrypt and decrypt using a Cloud KMS key.
- `workload_provider_name` (String) The fully qualified workload provider path. This should be in the format `projects/{project_number}/locations/global/workloadIdentityPools/{workload_identity_pool_id}/providers/{workload_identity_pool_provider_id}`.

### Optional

- `organization` (String) Name of the organization. If omitted, organization must be defined in the provider config.

### Read-Only

- `id` (String) The ID of the GCP OIDC configuration.
