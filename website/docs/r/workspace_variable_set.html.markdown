# Resource: tfe_workspace_variable_set

Adds and removes a workspace from a variable set's scope.

~> **Note:** `tfe_variable_set` has a deprecated argument `workspace_ids` that should not be used alongside this resource. They manage the same attachments and are mutually exclusive.

## Example Usage

```terraform
# Basic usage

resource "tfe_variable_set" "example" {
  name         = "my-variable-set"
  description  = "Example fixture variable set."
  organization = tfe_organization.example.name
}

resource "tfe_workspace_variable_set" "test" {
  variable_set_id = tfe_variable_set.example.id
  workspace_id    = tfe_workspace.example.id
}
```
