# Action: tfe_query_run

Creates a query run in an HCP Terraform or Terraform Enterprise workspace.

This initiates a query run within a specified workspace. This action allows you to execute a query on a workspace either against a specific configuration version or by waiting for the latest configuration version to be available.

## Example Usage

```terraform
# Using a Specific Configuration Version ID

resource "tfe_workspace" "ws" {
  name         = "example-workspace"
  organization = "my-organization"
}

resource "tfe_variable" "var" {
  key          = "my_key"
  value        = "my_value"
  category     = "terraform"
  workspace_id = tfe_workspace.ws.id

  # Trigger the query run after the variable is created or updated
  lifecycle {
    action_trigger {
      events  = [after_create, after_update]
      actions = [action.tfe_query_run.with_cv_id]
    }
  }
}

action "tfe_query_run" "with_cv_id" {
  config {
    workspace_id             = tfe_workspace.ws.id
    configuration_version_id = "cv-ntv3HbhJqvFzamy7"

    variables = {
      "animals" = "5"
    }
  }
}
```

```terraform
# Wait for the Latest Configuration Version

resource "tfe_workspace" "ws" {
  name         = "example-workspace"
  organization = "my-organization"
}

resource "tfe_variable" "var" {
  key          = "my_key"
  value        = "my_value"
  category     = "terraform"
  workspace_id = tfe_workspace.ws.id

  lifecycle {
    action_trigger {
      events  = [after_create, after_update]
      actions = [action.tfe_query_run.wait_for_latest]
    }
  }
}

action "tfe_query_run" "wait_for_latest" {
  config {
    workspace_id                  = tfe_workspace.ws.id
    wait_for_latest_configuration = true

    variables = {
      "animals" = "5"
    }
  }
}
```

### Invoking the action directly

```shell
terraform apply -invoke=action.tfe_query_run.wait_for_latest
```

## Schema

### Required

- `workspace_id` (String) The ID of the workspace where the query run will be executed.

### Optional

- `configuration_version_id` (String) A specific Configuration Version ID to use for the query run (e.g., "cv-ntv3HbhJqvFzamy7"). Exactly one of configuration_version_id or wait_for_latest_configuration must be provided.
- `variables` (Map of String) A map of key-value string pairs representing variables to pass directly into the query run.
- `wait_for_latest_configuration` (Boolean) A boolean flag that, when set to true, tells the action to wait for and use the latest configuration version available in the workspace. Exactly one of wait_for_latest_configuration or configuration_version_id must be provided.
