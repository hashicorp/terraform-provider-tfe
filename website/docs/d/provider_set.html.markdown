# Data Source: tfe_provider_set

Gets a provider set by name.

~> **Warning:** This data source is currently in beta and isn't generally available to all users. It is subject to change or be removed.

## Example Usage

```terraform
# Basic usage

data "tfe_provider_set" "my_provider_set" {
  name         = "example-provider-set"
  organization = "example-org"
}
```

## Schema

### Required

- `name` (String) The name of the provider set.

### Optional

- `organization` (String) Name of the organization. If omitted, organization must be defined in the provider config.

### Read-Only

- `description` (String) The description of the provider set.
- `global` (Boolean) Whether the provider set applies globally.
- `id` (String) The ID of the provider set.
- `priority` (Boolean) Whether the provider set takes priority over provider sets with more specific scopes.
- `project_ids` (Set of String) The IDs of the projects attached to the provider set.
- `provider_source` (String) Source address of the provider, e.g. `registry.terraform.io/hashicorp/tfe`.
- `workspace_ids` (Set of String) The IDs of the workspaces attached to the provider set.
