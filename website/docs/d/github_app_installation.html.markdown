# Data Source: tfe_github_app_installation

Gets information about the Github App installation.

At least one of `installation_id` or `name` must be set.

## Example Usage

```terraform
# Finding a Github App Installation by its installation ID

data "tfe_github_app_installation" "gha_installation" {
  installation_id = 12345678
}
```

```terraform
# Finding a Github App Installation by its name

data "tfe_github_app_installation" "gha_installation" {
  name = "github_username_or_organization"
}
```

## Schema

### Optional

- `installation_id` (Number) ID of the Github Installation. The installation ID can be found in the URL slug when visiting the installation's configuration page, e.g `https://github.com/settings/installations/12345678`.
- `name` (String) Name of the Github user or organization account that installed the app.

### Read-Only

- `id` (String) The internal ID of the Github Installation. This is different from the `installation_id`.
