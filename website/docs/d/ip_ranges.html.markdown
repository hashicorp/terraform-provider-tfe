# Data Source: tfe_ip_ranges

Gets a list of HCP Terraform's IP ranges. For more information about these IP ranges, view our [documentation about HCP Terraform IP Ranges](https://developer.hashicorp.com/terraform/cloud-docs/architectural-details/ip-ranges).

## Example Usage

```terraform
# Basic usage

data "tfe_ip_ranges" "addresses" {}

output "notifications_ips" {
  value = data.tfe_ip_ranges.addresses.notifications
}
```
