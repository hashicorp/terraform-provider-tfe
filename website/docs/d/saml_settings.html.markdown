# Data Source: tfe_saml_settings

(Only for Terraform Enterprise) Gets information on SAML settings.

This requires admin token configuration. See example usage for incorporating an admin token in your provider config.

## Example Usage

```terraform
# Basic usage

variable "token" {
  description = "An access token"
}

variable "admin_token" {
  description = "An admin access token"
}

variable "hostname" {
  description = "The HCP Terraform or Enterprise hostname."
  default     = "app.terraform.io"
}

provider "tfe" {
  hostname = var.hostname
  token    = var.token
}

provider "tfe" {
  alias    = "admin"
  hostname = var.hostname
  token    = var.admin_token
}

data "tfe_saml_settings" "foo" {
  provider = tfe.admin
}
```
