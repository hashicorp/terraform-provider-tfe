# Data Source: tfe_registry_provider

Gets a public or private provider from the private registry.

## Example Usage

```terraform
# A private provider

data "tfe_registry_provider" "example" {
  organization = "my-org-name"
  name         = "my-provider"
}
```

```terraform
# A public provider

data "tfe_registry_provider" "example" {
  organization  = "my-org-name"
  registry_name = "public"
  namespace     = "hashicorp"
  name          = "aws"
}
```
