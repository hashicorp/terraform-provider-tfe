# Data Source: tfe_registry_provider_version_platforms

This data source can be used to retrieve all platforms for a provider version in the private registry.

## Example Usage

```terraform
# List all platforms for a provider version

data "tfe_registry_provider_version_platforms" "example" {
  organization = "my-org-name"
  name         = "my-provider"
  version      = "1.0.0"
}
```
