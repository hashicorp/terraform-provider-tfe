# Data Source: tfe_organization_membership

Gets information about an organization membership.

~> **Note:** This data source requires using the provider with HCP Terraform or Terraform Enterprise at least as recent as v202004-1.

~> **Note:** If a user updates their email address, configurations using the email address should be updated manually.

-> **Note**: While `email` and `username` are optional arguments, one or the other is required if `organization_membership_id` argument is not provided.

## Example Usage

```terraform
# Fetch by email

data "tfe_organization_membership" "test" {
  organization = "my-org-name"
  email        = "user@company.com"
}
```

```terraform
# Fetch by username

data "tfe_organization_membership" "test" {
  organization = "my-org-name"
  username     = "my-username"
}
```

```terraform
# Fetch by organization membership ID

data "tfe_organization_membership" "test" {
  organization               = "my-org-name"
  organization_membership_id = "ou-xxxxxxxxxxx"
}
```
