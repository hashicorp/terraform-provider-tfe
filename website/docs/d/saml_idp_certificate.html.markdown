# Data Source: tfe_saml_idp_certificate

(Only for Terraform Enterprise) Gets information on a trusted SAML Identity Provider certificate. Requires Terraform Enterprise v2.1.0 or later.

This requires admin token configuration. See example usage for incorporating an admin token in your provider config.

## Example Usage

```terraform
variable "admin_token" {
  description = "An admin access token"
}

variable "hostname" {
  description = "The Terraform Enterprise hostname."
  default     = "tfe.example.com"
}

provider "tfe" {
  hostname = var.hostname
  token    = var.admin_token
}

data "tfe_saml_idp_certificate" "primary" {
  id = "idpc-AbC123XyZ456"
}

output "primary_expires_at" {
  value = data.tfe_saml_idp_certificate.primary.expires_at
}
```

### Read-Only

- `cert` (String) The PEM encoded X.509 certificate as provided by the IdP.
- `cert_role` (String) The role of the certificate: `managed`, `legacy_primary` or `legacy_old`.
- `created_at` (String) The time the certificate was added, in RFC 3339 format.
- `display_name` (String) A human-readable label for the certificate.
- `expires_at` (String) The time the certificate expires, in RFC 3339 format.
- `fingerprint` (String) Colon-separated uppercase SHA-256 fingerprint of the certificate.
- `issuer` (String) The issuer of the certificate, derived from its O and CN fields.
