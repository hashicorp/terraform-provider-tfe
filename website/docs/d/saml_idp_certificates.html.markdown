# Data Source: tfe_saml_idp_certificates

(Only for Terraform Enterprise) Gets the list of trusted SAML Identity Provider certificates. Requires Terraform Enterprise v2.1.0 or later.

This requires admin token configuration. See example usage for incorporating an admin token in your provider config.

## Example Usage

```terraform
variable "admin_token" {
  description = "An admin access token"
}

variable "hostname" {
  description = "The Terraform Enterprise hostname."
  default     = "tfe.example.com"
}

provider "tfe" {
  hostname = var.hostname
  token    = var.admin_token
}

# All trusted certificates, including legacy ones.
data "tfe_saml_idp_certificates" "all" {}

# Only certificates whose display name contains "us-east" (case-insensitive).
data "tfe_saml_idp_certificates" "us_east" {
  display_name_match = "us-east"
}

output "certificate_expirations" {
  value = {
    for c in data.tfe_saml_idp_certificates.all.certificates : c.id => {
      display_name = c.display_name
      expires_at   = c.expires_at
    }
  }
}
```

## Schema

### Optional

- `display_name_match` (String) A case-insensitive substring to match against certificate display names. When omitted, all certificates are returned.

### Read-Only

- `certificates` (Attributes List) The trusted SAML IdP certificates, including legacy certificates, in the order returned by Terraform Enterprise: the `legacy_primary` certificate first, then `legacy_old`, then `managed` certificates by least recently updated. Updating a certificate, including renaming it, moves it to the end of the list, so prefer filtering by `id` or `display_name` over indexing. (see [below for nested schema](#nestedatt--certificates))
- `id` (String) ID of the data source. It is always `saml`.

### Nested Schema for `certificates`

Read-Only:

- `cert` (String) The PEM encoded X.509 certificate as provided by the IdP.
- `cert_role` (String) The role of the certificate: `managed`, `legacy_primary` or `legacy_old`.
- `created_at` (String) The time the certificate was added, in RFC 3339 format.
- `display_name` (String) A human-readable label for the certificate.
- `expires_at` (String) The time the certificate expires, in RFC 3339 format.
- `fingerprint` (String) Colon-separated uppercase SHA-256 fingerprint of the certificate.
- `id` (String) The ID of the IdP certificate (idpc-*).
- `issuer` (String) The issuer of the certificate, derived from its O and CN fields.
