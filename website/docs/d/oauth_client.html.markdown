# Data Source: tfe_oauth_client

Gets information about an OAuth client.

## Example Usage

```terraform
# Finding an OAuth client by its ID

data "tfe_oauth_client" "client" {
  oauth_client_id = "oc-XXXXXXX"
}
```

```terraform
# Finding an OAuth client by its name

data "tfe_oauth_client" "client" {
  organization = "my-org"
  name         = "my-oauth-client"
}
```

```terraform
# Finding an OAuth client by its service provider

data "tfe_oauth_client" "client" {
  organization     = "my-org"
  service_provider = "github"
}
```

## Schema

### Optional

- `name` (String) Name of the OAuth client (may be `null`).
- `oauth_client_id` (String) ID of the OAuth client.
- `organization` (String) The name of the organization in which to search.
- `service_provider` (String) The API identifier of the OAuth service provider. If set, must be one of: `ado_server`, `ado_services`, `bitbucket_data_center`,  `bitbucket_hosted`, `bitbucket_server`(deprecated), `github`, `github_enterprise`, `gitlab_hosted`, `gitlab_community_edition`, or `gitlab_enterprise_edition`.

### Read-Only

- `api_url` (String) The client's API URL.
- `callback_url` (String) OAuth callback URL to provide to the OAuth service provider.
- `created_at` (String) The date and time this OAuth client was created in RFC3339 format.
- `http_url` (String) The client's HTTP URL.
- `id` (String) The OAuth client ID. This will match `oauth_client_id`.
- `oauth_token_id` (String) The ID of the OAuth token associated with the OAuth client.
- `organization_scoped` (Boolean) Whether or not the OAuth client is scoped to all workspaces and projects in the organization.
- `project_ids` (Set of String) IDs of the projects that use the oauth client.
- `service_provider_display_name` (String) The display name of the OAuth service provider.
