# Data Source: tfe_admin_smtp_settings

Reads SMTP settings for Terraform Enterprise. Only applies to Terraform Enterprise and requires admin token configuration.

## Example Usage

```terraform
# Basic usage

variable "token" {
  description = "An access token"
}

variable "admin_token" {
  description = "An admin access token"
}

variable "hostname" {
  description = "The HCP Terraform or Enterprise hostname."
  default     = "app.terraform.io"
}

provider "tfe" {
  hostname = var.hostname
  token    = var.token
}

provider "tfe" {
  alias    = "admin"
  hostname = var.hostname
  token    = var.admin_token
}

data "tfe_admin_smtp_settings" "foo" {
  provider = tfe.admin
}
```
