# Data Source: tfe_org_max_token_ttl_policy

Retrieves the maximum time-to-live (TTL) policy for API tokens in an organization. This data source fetches the current TTL limits for organization, team, audit trail, and user tokens.

~> **Note:** This data source requires using the provider with HCP Terraform or an instance of Terraform Enterprise at least as recent as v2.0.1.

~> **Warning:** Maximum TTL policies are enforced immediately. Any existing tokens that exceed configured limits will stop working and return an "Unauthorized" error.

Each token type exposes two attributes: a human-readable duration string (e.g. `OrgTokenMaxTtl`) and a millisecond integer (e.g. `OrgTokenMaxTtlMs`). Use the duration string for display; use milliseconds for time arithmetic or comparisons.

If no TTL policy has been configured for a token type, the data source returns a default value of 2 years for that type.

To check whether the max TTL feature is enabled for an organization, use the `MaxTtlEnabled` attribute on the `TfeOrganization` resource or data source.
