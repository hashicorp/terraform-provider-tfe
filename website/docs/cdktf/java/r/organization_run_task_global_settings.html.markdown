# Resource: tfe_organization_run_task_global_settings

The tfe_organization_run_task_global_settings resource creates, updates and destroys the [global settings](https://developer.hashicorp.com/terraform/cloud-docs/workspaces/settings/run-tasks#global-run-tasks) for an [Organization Run task](https://developer.hashicorp.com/terraform/cloud-docs/workspaces/settings/run-tasks#creating-a-run-task). Your organization must have the `globalRunTask` [entitlement](https://developer.hashicorp.com/terraform/cloud-docs/api-docs#feature-entitlements) to use global run tasks.

## Example Usage

```terraform
# Basic usage

resource "tfe_organization_run_task_global_settings" "example" {
  task_id           = tfe_organization_run_task.example.id
  enabled           = true
  enforcement_level = "advisory"
  stages            = ["pre_plan", "post_plan"]
}

resource "tfe_organization_run_task" "example" {
  organization = "org-name"
  url          = "https://external.service.com"
  name         = "task-name"
  enabled      = true
  description  = "An example task"
}
```

## Schema

### Required

- `enforcementLevel` (String) The enforcement level of the global task. Valid values are `advisory` and `mandatory`.
- `stages` (List of String) Which stages the task will run in. Valid values are one or more of `prePlan`, `postPlan`, `preApply` and `postApply`.
- `taskId` (String) The ID of the run task which will have the global settings applied.

### Optional

- `enabled` (Boolean) Whether the run task will be applied globally.

### Read-Only

- `id` (String) The ID of the Run task global settings.
