# Resource: tfe_organization_module_sharing

~> **Deprecated:** The `tfeOrganizationModuleSharing` resource is deprecated. Use `tfeAdminOrganizationSettings` instead, which allows the management of the global module sharing setting. They attempt to manage the same resource and are mutually exclusive.
